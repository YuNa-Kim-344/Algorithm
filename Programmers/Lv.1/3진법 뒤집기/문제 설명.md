# 3진법 뒤집기

## 📌 문제 설명

자연수 `n`이 매개변수로 주어집니다.  
정수 `n`을 **3진법으로 변환한 뒤**, 그 값을 **앞뒤로 뒤집고**,  
다시 이를 **10진법으로 표현한 수**를 반환하는 함수 `solution`을 완성하세요.

---

## ⚠️ 제한사항

- `n`은 **1 이상 100,000,000 이하**인 자연수입니다.

---

## 📊 입출력 예

| n | result |
|---|--------|
| 45 | 7 |
| 125 | 229 |

---

## 📝 입출력 예 설명

### ✔️ 입출력 예 #1

| 단계 | 값 |
|---|---|
| n (10진법) | 45 |
| n (3진법) | 1200 |
| 앞뒤 반전 (3진법) | 0021 |
| 10진법으로 변환 | 7 |

따라서 **7을 return** 합니다.

---

### ✔️ 입출력 예 #2

| 단계 | 값 |
|---|---|
| n (10진법) | 125 |
| n (3진법) | 11122 |
| 앞뒤 반전 (3진법) | 22111 |
| 10진법으로 변환 | 229 |

따라서 **229를 return** 합니다.

---

## 🧠 문제 핵심 요약

- 10진수 → 3진수 변환
- 3진수 문자열을 앞뒤로 뒤집기
- 뒤집힌 3진수를 다시 10진수로 변환
- 각 단계는 **순서가 매우 중요**
