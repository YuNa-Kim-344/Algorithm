# 나머지가 1이 되는 수 찾기

## 문제 설명

자연수 n이 주어졌을 때, n을 어떤 자연수 x로 나눈 나머지가 1이 되도록 하는 가장 작은 x를 구하는 문제입니다.

즉, 아래 조건을 만족하는 가장 작은 자연수 x를 반환하면 됩니다.

text n % x == 1 

---

## 풀이 방법

x는 1부터 차례대로 확인하면 됩니다.

- n % x == 1인지 검사한다.
- 조건을 만족하는 첫 번째 x가 가장 작은 값이다.
- 따라서 바로 반환한다.

n은 최대 1,000,000이므로 단순 반복문으로 충분히 해결할 수 있습니다.

---

## 예시

### n = 10

text 10 % 1 = 0 10 % 2 = 0 10 % 3 = 1 

따라서 정답은 3입니다.

### n = 12

text 12 % 1 = 0 12 % 2 = 0 ... 12 % 11 = 1 

따라서 정답은 11입니다.

---

## Python 코드

python def solution(n):     for x in range(1, n):         if n % x == 1:             return x 

---

## Java 코드

java class Solution {     public int solution(int n) {         for (int x = 1; x < n; x++) {             if (n % x == 1) {                 return x;             }         }          return 0;     } } 

---

## 시간 복잡도

text O(n) 

최악의 경우 1부터 n - 1까지 확인합니다.

## 공간 복잡도

text O(1) 

추가 배열이나 자료구조를 사용하지 않습니다.
