# 삼총사 문제 설명

## 📌 문제 개요

한국중학교에 다니는 학생들은 각자 **정수 번호**를 가지고 있습니다.  
이 중 **서로 다른 3명의 학생을 선택했을 때**, 그들의 정수 번호의 **합이 0**이 되면  
이 세 학생을 **삼총사**라고 합니다.

학생들의 번호가 담긴 정수 배열 `number`가 주어질 때,  
**삼총사를 만들 수 있는 방법의 수**를 구하는 것이 목표입니다.

---

## 📥 입력

- `number`: 학생들의 정수 번호를 담은 배열

---

## 📤 출력

- 삼총사를 만들 수 있는 **경우의 수** (정수)

---

## ⚠️ 제한사항

- `3 ≤ number의 길이 ≤ 13`
- `-1,000 ≤ number의 각 원소 ≤ 1,000`
- **서로 다른 학생이라면 정수 번호가 같을 수 있음**
- 학생의 **순서는 중요하지 않음** (조합)

---

## ✨ 삼총사의 조건

- 서로 다른 **3명**의 학생을 선택
- 선택한 3명의 번호 합이 **0**
- 같은 조합은 **한 번만 계산**

---

## 📊 입출력 예

| number | result |
|------|--------|
| `[-2, 3, 0, 2, -5]` | `2` |
| `[-3, -2, -1, 0, 1, 2, 3]` | `5` |
| `[-1, 1, -1, 1]` | `0` |
