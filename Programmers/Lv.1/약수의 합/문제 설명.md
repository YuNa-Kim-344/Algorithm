# 약수의 합

## 문제 설명

정수 `n`을 입력받아 `n`의 약수를 모두 더한 값을 리턴하는 함수 `solution`을 완성해주세요.

## 제한 사항

- `n`은 `0` 이상 `3000` 이하인 정수입니다.

## 입출력 예

| n | return |
| --- | --- |
| 12 | 28 |
| 5 | 6 |

## 입출력 예 설명

### 입출력 예 #1

`12`의 약수는 `1`, `2`, `3`, `4`, `6`, `12`입니다.

이를 모두 더하면 `28`입니다.

### 입출력 예 #2

`5`의 약수는 `1`, `5`입니다.

이를 모두 더하면 `6`입니다.
