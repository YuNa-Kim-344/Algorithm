# 위장 (의상 조합 문제)

## 문제 설명
코니는 매일 다른 옷 조합을 입는 것을 좋아합니다.

예를 들어 코니가 가진 옷이 아래와 같다고 합시다:

| 종류   | 이름                         |
|--------|------------------------------|
| 얼굴   | 동그란 안경, 검정 선글라스   |
| 상의   | 파란색 티셔츠                |
| 하의   | 청바지                       |
| 겉옷   | 긴 코트                      |

- 코니는 각 **종류별로 최대 1가지 의상**만 착용할 수 있습니다.  
  (예: 동그란 안경과 검정 선글라스를 동시에 착용할 수는 없음)
- 착용한 의상의 일부가 겹치더라도, **다른 의상이 겹치지 않거나 새로운 의상을 추가한 경우** 서로 다른 방법으로 계산합니다.
- 코니는 하루에 최소 **한 개 이상의 의상**은 입습니다.

의상이 담긴 2차원 배열 `clothes`가 주어질 때, **서로 다른 옷 조합의 수**를 반환하는 `solution` 함수를 작성하세요.

---

## 제한사항
- `clothes`의 각 행은 `[의상의 이름, 의상의 종류]`로 이루어져 있음
- 의상의 수: `1 ≤ clothes.length ≤ 30`
- 같은 이름을 가진 의상은 존재하지 않음
- 문자열 길이: `1 ≤ length ≤ 20`
- 문자열은 알파벳 소문자 또는 `_` 로만 구성됨

---

## 입출력 예시

| clothes                                                                 | return |
|-------------------------------------------------------------------------|--------|
| `[["yellow_hat", "headgear"], ["blue_sunglasses", "eyewear"], ["green_turban", "headgear"]]` | 5      |
| `[["crow_mask", "face"], ["blue_sunglasses", "face"], ["smoky_makeup", "face"]]`              | 3      |

---

## 입출력 예 설명

### 예제 #1
- headgear → yellow_hat, green_turban
- eyewear → blue_sunglasses

가능한 조합:
1. yellow_hat
2. blue_sunglasses
3. green_turban
4. yellow_hat + blue_sunglasses
5. green_turban + blue_sunglasses

    -> 총 **5가지**

---

### 예제 #2
- face → crow_mask, blue_sunglasses, smoky_makeup

가능한 조합:
1. crow_mask
2. blue_sunglasses
3. smoky_makeup

    -> 총 **3가지**
