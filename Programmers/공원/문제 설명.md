# 공원 돗자리 문제

## 문제 설명
지민이는 다양한 크기의 정사각형 모양 돗자리를 가지고 공원에 소풍을 나왔습니다.  
공원에는 이미 돗자리를 깔고 여가를 즐기는 사람들이 많아, 지민이가 깔 수 있는 **가장 큰 돗자리**가 무엇인지 확인하려고 합니다.  

예를 들어 지민이가 가진 돗자리 크기가 `5, 3, 2`이고, 공원의 배치가 아래와 같다면,  
지민이가 깔 수 있는 가장 큰 돗자리는 **3 x 3** 입니다.

(예시 그림: `10.jpg`)

---

## 입력
- `mats`: 지민이가 가진 돗자리들의 한 변 길이가 담긴 정수 리스트  
- `park`: 공원의 자리 배치를 나타내는 2차원 문자열 리스트  

조건:
- `park[i][j] = "-1"` → 빈 공간  
- `park[i][j] = "A" ~ "Z"` → 사람이 이미 차지한 자리  

---

## 출력
- 지민이가 깔 수 있는 돗자리 중 **가장 큰 정사각형의 한 변 길이**를 반환  
- 만약 아무 돗자리도 깔 수 없다면 `-1` 반환  

---

## 제한사항
- `1 ≤ mats.length ≤ 10`
- `1 ≤ mats[i] ≤ 20`  
- `mats` 원소는 **중복 없음**
- `1 ≤ park.length ≤ 50`
- `1 ≤ park[i].length ≤ 50`
- `park[i][j] ∈ {"-1", "A" ~ "Z"}`

---

## 입출력 예시

| mats     | park                                                                                                                                                                                                                  | result |
|----------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------|
| [5,3,2]  | `[["A","A","-1","B","B","B","B","-1"],["A","A","-1","B","B","B","B","-1"],["-1","-1","-1","-1","-1","-1","-1","-1"],["D","D","-1","-1","-1","-1","E","-1"],["D","D","-1","-1","-1","-1","-1","F"],["D","D","-1","-1","-1","-1","E","-1"]]` | 3      |

---

## 예시 설명
- 지민이가 가진 돗자리: 한 변 길이 = `[5, 3, 2]`
- 공원 배치에서 빈 공간(`"-1"`)을 확인했을 때, 가장 크게 깔 수 있는 정사각형 크기는 `3 x 3`
- 따라서 결과 = `3`

---

## 언어별 안내
- **C++**: `리스트(list)`는 **배열(array)** 의미와 동일합니다.  
- **Java**: `리스트(list)`는 **배열(array)**, `함수(function)`는 **메소드(method)** 의미와 동일합니다.  

예시:  
- C++ → "정수 리스트 numbers" = "정수 배열 numbers"  
- Java → "solution 함수" = "solution 메소드"
