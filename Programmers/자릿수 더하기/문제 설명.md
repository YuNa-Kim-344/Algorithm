# 자릿수 합 문제

## 문제 설명
자연수 `N`이 주어지면, `N`의 각 자릿수의 합을 구해서 반환하는 `solution` 함수를 작성하세요.  

예를 들어,  
- `N = 123` → `1 + 2 + 3 = 6`  
- `N = 987` → `9 + 8 + 7 = 24`

---

## 제한사항
- `N`의 범위: **100,000,000 이하의 자연수**

---

## 입출력 예시

| N   | answer |
|-----|--------|
| 123 | 6      |
| 987 | 24     |

---

## 예시 설명

### 예시 #1
- 입력: `123`  
- 계산: `1 + 2 + 3 = 6`  
- 출력: `6`

### 예시 #2
- 입력: `987`  
- 계산: `9 + 8 + 7 = 24`  
- 출력: `24`
